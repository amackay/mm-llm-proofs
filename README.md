A Metamath formalisation of
[Minkowski's theorem](https://en.wikipedia.org/wiki/Minkowski%27s_theorem),
generated by Claude. This is number 40 on
[Wiedijk's list of 100 theorems](https://www.cs.ru.nl/~freek/100/), one of
those the [Metamath 100](https://us.metamath.org/mm_100.html) page lists as
not yet formalised in Metamath (as of 15 September 2026).

Theorem statement:

> A convex, centrally symmetric, measurable subset of $\mathbb{R}^N$ whose
> $N$-dimensional Lebesgue measure exceeds $2^N$ contains a lattice point
> other than the origin.

The last statement in
[`mm100-040-minkowski/minkowski.mm`](mm100-040-minkowski/minkowski.mm) is
how this is stated in Metamath. The file includes `set.mm` at the commit in
[`mm100-040-minkowski/setmm-commit.txt`](mm100-040-minkowski/setmm-commit.txt).

## Verifying

From `mm100-040-minkowski/`:

```sh
curl -O "https://raw.githubusercontent.com/metamath/set.mm/$(cat setmm-commit.txt)/set.mm"
curl -O https://raw.githubusercontent.com/david-a-wheeler/mmverify.py/63a2aa3815cd5bf67892dbfc7f2048cbb177524c/mmverify.py
python3 mmverify.py minkowski.mm
```

No output means every proof verified.

```sh
git clone --depth 1 -b v0.198 https://github.com/metamath/metamath-exe ../metamath-exe
gcc -O2 -o metamath ../metamath-exe/*.c
./metamath 'read minkowski.mm' 'verify proof *' 'exit'
```

Ends with `All proofs in the database were verified`.
